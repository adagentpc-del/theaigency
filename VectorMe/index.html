    WHAT FILE DOES MY PRINTER NEED?

    A 60-second file guide

    SVG

    Best general-purpose editable vector file for many printers, sign shops, web tools and cutting workflows.

    Vector PDF

    Useful for commercial printers and vendors that prefer PDF while preserving vector geometry.

    PNG

    Transparent raster preview. Useful digitally, but it is not a true vector file.

    DST / PES

    Embroidery machine files created by a digitizer. Vector Me prepares the artwork; it does not invent stitch instructions.
